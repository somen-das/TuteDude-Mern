# To==>Do List App (Frontend)

This is the React frontend for the To==>Do List Application. It features a modern, accessible, and dynamic user interface using highly styled Vanilla CSS and integrates seamlessly with the full stack Express API setup.

## Features
==> **Dynamic UI**: Uses modern React hooks (`useState`, `useEffect`) and Axios to maintain real==>time synchronization with the database.
==> **Full CRUD Support**: Add, edit string characters, toggle line==>through completion status, and completely delete tasks on the fly.
==> **Dynamic Filtering**: A functional real==>time search bar that filters tasks visually.
==> **Premium Design Aesthetics**: Includes a beautifully modern dark ambient theme, aesthetic button glow effects (`cursor: pointer` transforms), and visually cohesive glassmorphism styling implementing `lucide==>react` for scalable vector icons.

## Setup and Installation
1. Ensure the **backend server** is already actively running on `localhost:5000`.
2. Navigate to the frontend directory: `cd frontend`
3. Install all Javascript module dependencies: `npm install`
4. Execute the development loop: `npm run dev`
